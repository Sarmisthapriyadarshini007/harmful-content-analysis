# 🛡️ SafeTube AI - Intelligent Content Moderation & Analysis

## 🚀 Overview
**SafeTube AI** is a next-generation, AI-powered platform designed to revolutionize how creators, moderators, and viewers interact with YouTube content. In an era where the internet is flooded with digital noise, our platform provides a robust, real-time dashboard to automatically scan, detect, and filter out harmful content—ensuring a safer, more constructive digital ecosystem for everyone.

---

## 💡 The Problem We're Solving
The rapid expansion of video-sharing platforms has brought unprecedented challenges:
- **Rampant Toxicity:** Creators struggle to manage toxic communities, cyberbullying, and harassment in their comment sections.
- **Misinformation & Scams:** Viewers are constantly exposed to misleading information, fake news, deepfakes, and financial scams.
- **Unscalable Moderation:** Manual moderation is virtually impossible at scale for channels receiving thousands of comments per hour.
- **Reactive Solutions:** Existing moderation tools are largely reactive (relying on user reports) rather than proactive, and they often lack the deep, context-aware AI needed to understand nuance.

## ✨ Innovation & Key Features
SafeTube AI replaces manual moderation with a **proactive, AI-driven approach**:

- 🔍 **Real-Time Video & Comment Analysis:** Simply paste any YouTube link, and our AI fetches and analyzes thousands of comments in seconds to identify toxicity, spam, and hate speech.
- 🛑 **Deep Misinformation & Scam Detection:** Employs advanced heuristics to calculate a "Fake News Probability" and flag deceptive content, clickbait thumbnails, and malicious links.
- 📊 **Creator Dashboard Integration:** Creators can securely connect their YouTube channel to monitor their channel's overall health, track automated moderation stats, and review flagged items in one centralized place.
- 🌡️ **Intuitive "Risk Meter":** Translates complex AI analysis into simple, actionable visual metrics (Safe, Low Risk, Medium Risk, High Risk) for immediate understanding.
- 🎨 **Premium User Experience:** Built with a stunning, highly responsive modern SaaS UI featuring dynamic micro-animations, glassmorphism, and a seamless Dark/Light mode toggle.

## 🛠️ Technology Stack
- **Frontend:** HTML5, CSS3 (Modern Flexbox/Grid, Custom CSS Variables), Vanilla JavaScript.
- **Design System:** Custom, premium UI tailored for a modern SaaS aesthetic (Navy dark theme with dynamic cyan/blue gradients).
- **Architecture:** Client-side routing mockup integrated with localized `localStorage` state management for a seamless, database-free demonstration flow.

## 🚀 How to Run Locally

Because the frontend is built with pure, optimized web technologies, running the project is incredibly simple:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Sarmisthapriyadarshini007/harmful-content-analysis.git
   ```
2. **Navigate to the project directory:**
   ```bash
   cd harmful-content-analysis
   ```
3. **Launch the Application:**
   Simply double-click on `login.html` or `register.html` to open it in your preferred modern web browser. No complex build tools or `npm install` steps are required to view the UI!
